# Test image sources

Small, openly licensed images used by the test suite. Each file was
downscaled to at most 320 px on its longest side and re-encoded as JPEG
(quality 85) to keep the repository light; the content is unchanged.

| File | Content | Source | License / attribution |
|---|---|---|---|
| `cat.jpg` | Close-up of a tabby cat | `skimage.data.chelsea` (scikit-image) | CC0 — Stefan van der Walt |
| `astronaut.jpg` | Astronaut in an orange spacesuit holding a helmet | `skimage.data.astronaut` (NASA) | Public domain (NASA) |
| `coffee.jpg` | A cup of coffee on a wooden table | `skimage.data.coffee` (scikit-image) | CC0 — Rachel Michetti |
| `rocket.jpg` | A rocket on a launch pad at dusk | `skimage.data.rocket` (SpaceX) | Public domain (SpaceX) |
| `horse.jpg` | Black silhouette of a horse | `skimage.data.horse` (scikit-image) | CC0 — Andreas Preuss |
| `camera.jpg` | Man using a camera on a tripod (black and white) | `skimage.data.camera` (scikit-image) | CC0 — Lav Varshney |
| `hubble.jpg` | Galaxies in deep space | `skimage.data.hubble_deep_field` (NASA) | Public domain (NASA) |
| `grace_hopper.jpg` | Woman in a US Navy uniform in front of the flag | matplotlib sample data (US Navy) | Public domain (US federal government work) |

Rules for this directory:

- Every image must list a source and an explicit open license above.
- No personal or private photos, ever.
- Keep files small: downscale before adding.
